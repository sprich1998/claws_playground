Interactive Personal Assistant Web App

This repository is a playground to build a browser-based personal assistant you can talk to directly. The goal is a fast, friendly assistant experience with streaming replies, memory, and optional voice.

Tech stack
- Next.js (App Router)
- TypeScript
- Minimal UI to start (can add Tailwind or shadcn later)

Quick start
- npm install
- npm run dev
- Open http://localhost:3000

Vision
- Real-time chat UI with streaming responses
- Persistent conversation history with basic memory
- Optional voice input and text-to-speech
- Settings for model, persona, and context size
- Future: integrate with OpenClaw gateway for unified messaging across channels
